┌──────────────────────────────────────────────────────────────────────────────┐
│                             HOW TO USE                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  STEP 1: Install Dependencies
  ────────────────────────────
  $ cd injera_ai
  $ pip install -r requirements.txt


  STEP 2: Test the System
  ────────────────────────
  $ python test_ai.py
  
  Expected output:
    ✅ ALL TESTS PASSED!


  STEP 3: Start the AI Server
  ────────────────────────────
  $ python server.py
  
  Expected output:
    🤖 INJERA AI SERVER STARTING
    Server will run on: http://localhost:5000
  
  Keep this terminal open!


  STEP 4: Integrate with HTML
  ────────────────────────────
  Follow the instructions in INTEGRATION_GUIDE.md to modify your
  injera_game.html file to call the AI server.


  STEP 5: Play!
  ──────────────
  Open injera_game.html in your browser and play against the AI.

┌──────────────────────────────────────────────────────────────────────────────┐
│                           KEY CONCEPTS                                       │
└──────────────────────────────────────────────────────────────────────────────┘

  GameState
  ─────────
  Complete snapshot of the game at any moment:
  • Board tiles (dishes, hot tokens, tahini)
  • Players (hands, scores, drinks)
  • Deck composition
  • Current turn
  • Reachable tiles per player

  Action
  ──────
  A single move a player can make:
  • Type (eat_dish, play_drink, rotate, etc.)
  • Target (tile coordinates)
  • Resources used (card or empty tile)
  • Sub-choices (which drink, which direction)

  Action Generator
  ────────────────
  Examines game state and finds ALL legal moves:
  • Checks reachability
  • Validates resources
  • Ensures rule compliance

  AI Player
  ─────────
  Chooses one action from legal options:
  • Beginner: Random selection
  • Intermediate: Heuristic scoring (TODO)
  • Advanced: Tree search (TODO)
  • Expert: Full optimization (TODO)

    async function getAIMove() {
        const response = await fetch('http://localhost:5000/ai_move', {
            method: 'POST',
            headers: {'Content-Type': 'application/json'},
            body: JSON.stringify({
                game_state: currentGameState,
                ai_level: 'beginner'
            })
        });
        
        const data = await response.json();
        return data.action;  // Execute this action in your game
    }
